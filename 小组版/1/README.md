## 数据获取（配套文件：数据获取.ipynb）
数据从哪来、用什么方法，全部写在 **我的代码/数据获取.ipynb**（演示用，默认不执行）：
- **主数据源 CSMAR 国泰安官方 API**（csmarapi）：三张财务报表、公告日期、财务指标库、公司信息、官方行情 TRD_Dalyr；
- **补充数据源东方财富公开接口**（requests + JSON）：日线三复权、沪深300、上证综指、分红送转；股本变动用 akshare；
- CSMAR 官方接口有单日下载配额限制，补充数据已与官方口径交叉验证（相关系数 0.99999989）。
汇报时请先讲这句：**主要数据来自 CSMAR，个别字段/时段用东财补充且已交叉验证。**
